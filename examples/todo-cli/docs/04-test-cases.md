## 1. 用例清单

FR-1~FR-5 的行为通过 CLI 层用例（TC-18 起）端到端验证；TC-04~TC-17 为对应业务/存储层单元测试，覆盖正常、边界、异常三类场景（对应 00-constitution 质量底线）。

### CLI 端到端用例（真实进程执行）

| 用例 ID | 来源需求 | 前置条件 | 步骤 | 输入 | 预期结果 | 失效检测点（实现错成什么样时本用例会失败） |

| TC-27 | FR-5 | #1 存在 | pri | `todo pri 1 low` | 退出码 0；随后 list 该行含 `[低]` | 优先级标签未更新时失败 |
| TC-28 | FR-5 | #1 不存在 | pri | `todo pri 99 high` | 退出码 1 | 退出码≠1 时失败 |
